# Acceptance criteria (unapproved proposals)

- [ ] Engineer: Intake does not silently fabricate missing facts.
- [ ] Engineer: Generated draft identifies artifact version and draft state.
- [ ] Lawyer: Actual mandatory fields, format and section requirements have been determined.
- [ ] Lawyer: Sample content has been edited/checked for domain correctness.
- [ ] Joint: At least one expert correction has been translated into a candidate rule and explicitly approved with scope.
- [ ] Joint: Next draft is tested against that rule and any false positive is captured.

Blocker: no actual legal expert review has occurred for these example artifacts.
